# 検証記録

2026-10-08、Windows x64 / MSVC 19.51 / JUCE 8.0.15。

## 完了した検証

- DebugとReleaseのVST3・Standaloneをビルド。
- CTest `analysis_and_plugin`：Debug 14.52秒、Release 4.42秒で成功。
- 32 / 44.1 / 48 / 96 / 192 kHz：同相、逆相、片チャンネル、90度位相差の1 kHz正弦波。
- 左右のゲイン差、独立ノイズ、無音、NaN/Inf、解析平均の減衰、再初期化。
- Hann窓のパワー正規化：振幅0.5の同相正弦波の全帯域合計が-9.03 dBFS（許容差0.02 dB）。
- Mono・Stereo音声の完全通過、0サンプルの追加レイテンシー。
- 表示設定の保存・復元、不正な保存データの無視。
- 解析キューの過負荷でも音声が変化しないこと、過負荷後の解析復帰。
- 新しい音声を入力しながらFreeze前後のプロット画素が一致すること。
- GUIを720×520、900×640、1440×1000でレンダリング。3D・Map・ヘルプの画像を確認。
- 実際のVST3バンドルをJUCEテストホストでスキャン・ロード。音声通過、状態保存、エディタのネイティブウィンドウ接続・再接続、44.1 kHzへの再初期化。
- リポジトリ内の一時配置先へ2回インストールし、フォルダが二重にならないことと、配置されたバイナリのSHA-256がビルド結果と一致すること。

画像は `build/debug/verification/` と `build/release/verification/` に再生成されます。テストホストのネイティブウィンドウは非表示で作成します。
